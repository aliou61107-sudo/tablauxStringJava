Chapitre 2 : Tableaux et chaînes de caractères

Résumé du cours de Mme Olfa Hamrouni, avec l'image de l'armoire pour tout retenir.

Tableaux statiques

L'image de l'armoireUn tableau est une armoire : un seul nom, des compartiments numérotés, un seul type de contenu, et une taille fixée à la fabrication.

Déclarer et remplir

int[] scores = {1000, 1500, 2490, 6450};   // armoire remplie dès la fabrication
int[] tab = new int[4];                    // armoire vide de 4 compartiments
tab[0] = 1000;                             // on range une valeur

Les indices

  • On compte à partir de 0 : pour n compartiments, les indices vont de 0 à n - 1.
  • tab.length donne la taille (sans parenthèses). Le dernier indice est tab.length - 1.
  • scores[4] sur une armoire de 4 cases lance ArrayIndexOutOfBoundsException : le compartiment n'existe pas.

Valeurs par défaut d'une armoire neuve

TypeValeur par défaut
int0
double0.0
booleanfalse
char'\u0000'
objet (dont String)null (aucune enveloppe)

null : aucune enveloppe. "" : une enveloppe vide. " " : une enveloppe avec un espace dedans.

Parcourir un tableau

// for : donne l'indice i
int somme = 0;
for (int i = 0; i < notes.length; i++) {
    somme += notes[i];
}

// while : départ avant, condition, pas dans le corps
int i = 0;
while (i < notes.length) {
    somme += notes[i];
    i++;                       // oublié = boucle infinie
}

// do while : la condition est testée à la fin
int j = 0;
do {
    somme += notes[j];
    j++;
} while (j < notes.length);

// for-each : « pour chaque valeur »
for (int val : notes) {
    System.out.print(val + " | ");
}
  • Avec i <= notes.length, le dernier tour vaut notes[30] pour 30 cases : erreur ArrayIndexOutOfBoundsException.
  • Le do while entre toujours au moins une fois, même sur un tableau de 0 case.
Le for-each travaille sur une photocopie val = val * 2; change la copie, pas l'armoire. Pour modifier le tableau, il faut l'indice : tab[i] *= 2;. Le for-each ne peut pas non plus parcourir deux tableaux à la fois ni comparer un élément à son suivant.

Tableaux à deux dimensions

L'image de la salle de cinémaDes rangées (lignes) et des fauteuils (colonnes). Il faut deux numéros : tab[ligne][colonne].
double[][] statistiques = new double[24][12];   // 24 lignes, 12 colonnes
statistiques[2][2] = 35.5;                      // 3e gouvernorat, mars

int[][] tab = new int[3][2];
for (int i = 0; i < tab.length; i++) {          // tab.length = nombre de lignes
    for (int j = 0; j < tab[i].length; j++) {   // tab[i].length = colonnes de la ligne i
        System.out.print(tab[i][j] + " ");
    }
}

Un tableau à deux dimensions est un tableau de tableaux : tab[i] est la ligne i, qui est elle-même un tableau.

ArrayList : l'armoire à taille variable

import java.util.ArrayList;

ArrayList<String> fruits = new ArrayList<>();
fruits.add("pomme");        // [pomme]
fruits.add("banane");       // [pomme, banane]
fruits.add(1, "kiwi");      // [pomme, kiwi, banane]
fruits.set(2, "mangue");    // [pomme, kiwi, mangue]
MéthodeEffet
add(e)ajoute à la fin
add(i, e)insère à la position i, les suivants reculent
set(i, e)remplace le contenu de la position i, la taille ne change pas
remove(i)supprime par position
remove(objet)supprime la première occurrence de cette valeur
clear()vide la liste
get(i)donne l'élément à la position i
size()nombre d'éléments
isEmpty()vrai si la liste est vide
contains(e)vrai si e est dans la liste
indexOf(e)position de la première occurrence, ou -1 si introuvable
  • -1 signifie « introuvable », car 0 est déjà une vraie position (le premier compartiment).
  • Tri : Collections.sort(fruits); (croissant) et Collections.sort(fruits, Comparator.reverseOrder()); (décroissant).
  • Le type entre < > est un type évolué : Integer pour int, Double pour double.
  • Une ArrayList est une classe qui implémente List, elle-même dans Collection, elle-même dans Iterable.

== ou equals

L'image des deux enveloppesDeux enveloppes contiennent chacune 2000 dinars. == demande « est-ce la même enveloppe ? ». equals demande « le contenu est-il le même ? ».
ArrayList<Integer> tab = new ArrayList<>();
tab.add(2000);
tab.add(2000);
System.out.println(tab.get(0) == tab.get(1));        // false
System.out.println(tab.get(0).equals(tab.get(1)));   // true

Règle : pour comparer le contenu d'objets (éléments d'une ArrayList, String), on utilise equals.

Chaînes de caractères

String s'écrit avec des guillemets doubles "...", char avec des guillemets simples '...'. Un String est un collier de perles : chaque perle est un caractère, numérotée à partir de 0.

L'image de la plaque gravéeUne chaîne est immuable. Une méthode de modification ne change jamais la plaque d'origine : elle en fait graver une nouvelle, qu'il faut ranger dans une variable.
String s = "  Bonjour  ";
s.trim();                    // résultat perdu, s ne change pas
s = s.trim();                // s contient maintenant "Bonjour"
String t = s.replace("Bon", "Bonne");   // s reste inchangée
MéthodeEffet
charAt(i)le caractère à la position i
length()nombre de caractères, espaces compris (avec des parenthèses)
substring(début, fin)extrait de début jusqu'à fin non incluse
indexOf(x)position de la première occurrence, ou -1
replace(ancien, nouveau)remplace toutes les occurrences
trim()supprime les espaces au début et à la fin
toUpperCase(), toLowerCase()majuscules, minuscules
contains, startsWith, endsWithtests de présence
split(séparateur)découpe en un tableau de morceaux
equals, equalsIgnoreCasecompare le contenu, avec ou sans tenir compte de la casse

Le premier et le dernier mot

String phrase = "Salut tout le monde";
String premier = phrase.substring(0, phrase.indexOf(' '));   // "Salut"
String[] mots = phrase.split(" ");                          // 4 morceaux
String dernier = mots[mots.length - 1];                      // "monde"

Tester un caractère

char c = "Java8".charAt(4);            // '8'
Character.isDigit(c);                  // true
Character.isLetter(c);                 // false
// aussi : isLetterOrDigit, isUpperCase, isLowerCase, isAlphabetic, isWhitespace

Pièges à retenir

Les erreurs les plus fréquentes du chapitre
  • <= à la place de < dans une boucle sur length : l'indice dépasse l'armoire.
  • length pour un tableau, length() pour un String, size() pour une ArrayList.
  • get(i) est réservé à l'ArrayList : pour un String, c'est charAt(i).
  • Le for-each modifie une copie, pas le tableau.
  • Un String ne se modifie pas : on réaffecte le résultat (s = s.trim();).
  • substring(0, fin) : la position fin n'est pas incluse.
  • split(" ") coupe seulement aux espaces : la ponctuation reste collée au mot.
  • Ne pas oublier import java.util.ArrayList; en haut du fichier.
